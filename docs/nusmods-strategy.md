# NUSMods adapter strategy

Strategy: `PUBLIC_API`

Contract: stable, read-only NUSMods JSON API

Evidence:

- API documentation: `https://api.nusmods.com/v2/`
- Module catalog: `GET /v2/{academic-year}/moduleList.json`
- Module details and timetable: `GET /v2/{academic-year}/modules/{module-code}.json`
- Verified for academic year `2026-2027`: the catalog and `CS1010S` module document returned HTTP 200 JSON with module metadata and semester timetables.

NUSMods describes the API as public, without authentication or a published rate limit. DamNUS performs only `GET` requests and fetches the catalog once per search; it does not fan out into per-module detail requests. The data is static JSON generated by NUSMods from NUS sources and refreshed daily.

Invalid inputs, missing modules, empty filters, network failures, and malformed responses use OpenCLI typed errors. Unit tests cover the response projection and filtering contract, while live smoke tests cover the current public endpoint.
